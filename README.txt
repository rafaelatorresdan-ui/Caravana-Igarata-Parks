ORLANDO PARKS GUIDE - VERSAO COM EDITOR VISUAL

COMO USAR
1. Abra index.html no navegador.
2. Clique em "Editar guia" no topo.
3. Escolha o parque e clique na atracao que quer editar.
4. Altere nome, area, categoria, prioridade, foto, descricao e observacao.
5. Clique em "Salvar alteracoes".
6. Para posicionar o pin, arraste-o diretamente sobre o mapa enquanto o modo de edicao estiver aberto.
7. Use "+ Nova atracao" para cadastrar outra e "Excluir atracao" para remover.

FOTOS
- Coloque as fotos em assets/attractions/
- No campo Foto, escreva por exemplo: assets/attractions/tron.jpg

MAPAS
- Os mapas ficam em assets/maps/
- Os nomes esperados continuam definidos no data.js.

SALVAMENTO
- Enquanto voce edita, o navegador guarda as mudancas automaticamente neste computador.
- Quando terminar, clique em "Exportar data.js".
- O navegador baixara um novo arquivo data.js.
- Substitua o data.js antigo da pasta do site por esse arquivo novo.
- Depois disso, o conteudo editado passa a fazer parte dos arquivos que voce podera publicar no GitHub Pages.

IMPORTANTE
- A informacao "Melhor horario" foi removida.
- O botao "Restaurar original" apaga apenas as edicoes guardadas no navegador e volta a ler o data.js da pasta.

NOVO: No modo Editar guia, o campo 'Informacoes adicionais' permite alterar o quadro inferior do parque diretamente pelo site.
